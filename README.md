# 🏋️‍♂️ Spor Salonu Web Sitesi

Bu proje, bir spor salonunun işleyişini dijital ortama taşıyan, üyelerin ve yöneticilerin işini kolaylaştıran kapsamlı bir web uygulamasıdır.

## 🚀 Kullanılan Teknolojiler

* **Backend:** C# (.NET) /
* **Veritabanı:** Microsoft SQL Server (SSMS)
* **Frontend:** HTML, CSS, JavaScript 

## 💻 Kurulum ve Çalıştırma

Projeyi bilgisayarınızda çalıştırmak için şu adımları izleyebilirsiniz:

1. Repoyu bilgisayarınıza klonlayın:
   ```bash
   git clone [https://github.com/Furkan003/SporSalonu-WebSitesi.git](https://github.com/Furkan003/SporSalonu-WebSitesi.git)
   ```
2. Veritabanı bağlantı ayarlarını (Connection String) kendi SQL Server yapılandırmanıza göre güncelleyin.
3. Gerekli bağımlılıkları/kütüphaneleri yükleyin ve projeyi başlatın.

## 📌 Temel Özellikler

* 👤 Yeni üye kayıt sistemi ve kullanıcı girişi
* 📅 Antrenman programları ve ders takvimi görüntüleme
* 💳 Üyelik paketleri ve abonelik durumu takibi
* ⚙️ Gelişmiş yönetici (Admin) paneli
